AUREVON — ЕДИНЫЙ АРХИВ

Распакуйте ZIP в отдельную папку.

01-PRIVATE-BACKUP — частная резервная копия локального проекта, доступных локальных баз, материалов и настроек. НЕ загружать эту папку или весь единый архив в GitHub и не публиковать: внутри могут быть секреты и данные.

02-DEPLOY-TO-GITHUB — очищенная локальная сборка для переноса. Только содержимое ЭТОЙ папки предназначено для репозитория. Перед заменой сравните с актуальным main. Railway запускает проект из репозитория, а не из этого ZIP.

В каждой папке находится подробная инструкция INSTRUCTION-RU.txt по восстановлению, переносу, настройке сервисов и Telegram.

ОГРАНИЧЕНИЯ: секретные Variables и рабочие базы Railway не экспортированы. Точное соответствие локального кода текущей опубликованной версии не подтверждено. Это проверенная локальная резервная копия, а не полный снимок работающего сервера. Экспорт Railway был остановлен по указанию владельца.

FILES-SHA256.json содержит контрольные суммы всех вложенных файлов. Внешний файл .sha256 проверяет весь ZIP.
